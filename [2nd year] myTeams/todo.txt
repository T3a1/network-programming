The 3 main parts of the myTeams project are:
	I 	- The Server
	II 	- The Client
	III - The Save and Load features

Project schema:

		client 										|			server
													|
													|
/create <team name> <team description> 				|		CRT
/create <channel name> <chanel description>			|		CRC
/create <thread title> <thread description>			|		CRH
/create <comment body>								|		CRR

/use
/use <team_uuid>									|		USE <team_uuid>
/use <team_uuid> <channel_uuid>						|		USE <team_uuid> <channel_uuid>
/use <team_uuid> <channel_uuid> <thread_uuid>		|		USE <team_uuid> <channel_uuid> <thread_uuid>

The context (use) will be handled directly by the client.
The server-side USE call will only exist to say if uuids exist and are valid.

For error handling
We currently have 3 types:
	Critical / Major / Minor
It will probably be interesting to implement error types with 3 digits code (RFC style).
Better error handling and will help for client to parse answers from the server.

IMPORTANT
Direct messages have not been discussed yet.
