# Network programming

Network projects from Epitech: TCP servers and clients written directly on top
of the BSD socket API, with a single `poll()` loop handling every connection.

| Project | Summary | Language |
|---------|---------|----------|
| [myftp](myftp) | FTP server following RFC 959: authentication, navigation, active and passive transfers | C |
| [myteams](myteams) | Team chat (teams, channels, threads, private messages) with its own protocol and persistence | C++ |
